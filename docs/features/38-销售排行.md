# 功能开发文档 · 38·销售排行

> 项目：宠老板复刻 · 里程碑：M6（F-063，P1 · 二期）
> 作用：商品/服务/员工业绩排行，辅助经营者识别畅销品与高效员工。

---

## 1. 功能概述

按区间维度输出**销售排行**：商品销量/SKU 排行、服务次数排行、营销活动让利排行、员工业绩排行。

- 核心产出：多维度排行接口 + 排行页。
- 前置：M3 订单明细、M4 商品/服务、F-032 员工业绩。

---

## 2. 数据来源

```mermaid
flowchart TD
    ORDER_ITEM[(order_item)] --> RANK[排行聚合]
    SERVICE[(work_order)] --> RANK
    CLERK[(sale_order.clerk_id)] --> RANK
    RANK --> A1[商品销量榜]
    RANK --> A2[服务次数榜]
    RANK --> A3[员工业绩榜]
```
