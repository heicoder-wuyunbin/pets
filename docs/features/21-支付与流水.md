# 功能开发文档 · 21·支付与流水

> 项目：宠老板复刻 · 里程碑：M3（F-033，P1）
> 作用：管理收款支付方式与收银流水（payment 表），提供现金流水（cashbook）对账，支撑退款联动。

---

## 1. 功能概述

实现**支付记录与收银流水**：收银时按支付方式写入 `payment` 流水，现金收付记入 `cashbook`；支持流水查询与退款流水回冲。

- 核心产出：支付流水、现金流水接口、流水查询页。
- 前置：F-030 收银、F-031 订单。

---

## 2. 数据流

```mermaid
flowchart TD
    OP[收银/退款] --> PAY[写入 payment]
    OP -->|现金| CASH[写入 cashbook]
    QUERY[流水页] --> LIST[POST /payment/page]
    LIST --> PAY
    LIST2[现金流水页] --> CASH
    REFUND[退款] --> PAY2[打标记/反向流水]
```

## 4. 表结构

### 4.1 支付流水 `payment`
| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint PK | 主键 |
| order_id | bigint | 订单 |
| pay_type | varchar | cash/wechat/alipay/... |
| amount | decimal | 金额 |
| status | tinyint | 1 成功 0 失败 |
| biz_no | varchar | 外部流水号 |
| create_time | datetime | |

### 4.2 现金流水 `cashbook`
| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint PK | 主键 |
| shop_id | bigint | 租户 |
| type | tinyint | 收入/支出 |
| amount | decimal | 金额 |
| biz_type | varchar | 收款/找零/提现/退款 |
| order_id | bigint | 关联订单 |
| clerk_id | bigint | 经办人 |
| memo | varchar | 备注 |
| create_time | datetime | |
