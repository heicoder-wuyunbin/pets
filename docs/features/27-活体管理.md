# 功能开发文档 · 27·活体管理

> 项目：宠老板复刻 · 里程碑：M4（F-042，P1）
> 作用：宠物活体（在售宠物）批次管理，含品相等级、价格、状态，作为商品的特例来源。

---

## 1. 功能概述

管理**活体宠物批次**（如整批小猫/小狗）：每批活体含品种、品相等级、数量、单价、状态，销售时可整批或按只结算。

- 核心产出：活体批次 CRUD、状态、销售。
- 前置：M0、Redis 号段、M4 商品可联动（可将活体挂到商品）。

---

## 2. 需求明细

| 编号 | 功能点 | 说明 | 优先级 |
|------|--------|------|--------|
| R-01 | 活体批次 CRUD | 品种/品相/数量/价格 | P1 |
| R-02 | 状态 | 在售/已售/下架 | P1 |
| R-03 | 销售出 | 售出减数量 | P1 |

---

## 3. 表结构 `live`
| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint PK | 主键 |
| shop_id | bigint | 租户 |
| goods_id | bigint | 关联商品(可空) |
| variety | varchar | 品种 |
| grade | varchar | 品相等级 |
| quantity | int | 在售数量 |
| price | decimal | 单价 |
| status | tinyint | 1 在售 0 下架 |
| pic | varchar | 图片 |

---

## 4. 接口设计
- `POST /api/v1/live/page`：活体列表。
- `POST /api/v1/live/save` / `status`。
- 销售时调用 `stock/deduct` 或 `quantity-1` 联动。
