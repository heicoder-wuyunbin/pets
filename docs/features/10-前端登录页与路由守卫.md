# 功能开发文档 · 10·前端登录页与路由守卫

> 项目：宠老板复刻 · 里程碑：M1（F-014，P0）
> 作用：实现前端登录/注册/忘记密码统一入口，完成 token 管理、记住密码与路由守卫，打通「未登录进不来、登录即进系统」。

---

## 1. 功能概述

在前端工程骨架上落地完整**登录体验**：登录页（含记住密码）、注册页、忘记密码页，通过 `authStore` 管理 token 与用户信息，`AuthGuard` 守卫路由，401 自动登出。

- 核心产出：`login/register/forget` 三页、`authStore`(persist)、`AuthGuard`。
- 前置：F-002 前端骨架、F-010~F-013 后端接口。

---

## 2. 登录成功流转

```mermaid
flowchart TD
    A[访访问任意受保护页] --> B{AuthGuard 有token?}
    B -->|否| L[/login]
    L --> C[输入账号密码]
    C --> D[authStore.login 调接口]
    D -->|成功| E[存储 token + 用户]
    E --> F[跳转进系统]
    D -->|401| G[清态跳登录]
```

## 3. 前端设计

### 3.1 authStore（Zustand + persist）
```ts
interface AuthState {
  token?: string; user?: UserInfo; shopId?: number;
  login(payload): Promise<void>;
  logout(): void;
  setToken(token): void;
}
// persist 中间件持久化到 localStorage
```
- `remember` 决定账号是否持久化（token 按持久化策略存 localStorage/sessionStorage）。

### 3.2 AuthGuard
- 无 token → `<Navigate to="/login" />`；有 token → 渲染子节点。
- 登录页若已有 token 则重定向进系统。

### 3.3 请求/响应（复用 request.tsx）
- 拦截器已挂 `Authorization`；`401` 触发 `logout` + 跳登录。
