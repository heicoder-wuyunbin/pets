# 功能开发文档 · 15·系统参数配置

> 项目：宠老板复刻 · 里程碑：M2（F-023，P1）
> 作用：提供可配置的系统参数项（键值对），供各模块读取默认值，避免硬编码。

---

## 1. 功能概述

实现 **KV 参数配置中心**：按租户维护系统参数（如短信开关、默认折扣、预约早间时间等），前端系统参数页编辑，后端统一读取。

- 核心产出：`sys_param` 表、参数 CRUD 接口、参数读取工具。
- 前置：M0、`sys_param` 表。

---

## 2. 数据流

```mermaid
flowchart TD
    PARAM[参数设置页] --> LIST[POST /sys-param/list]
    LIST --> DB[(sys_param)]
    PARAM --> SAVE[POST /sys-param/save]
    SAVE --> DB
    BIZ[业务服务] --> GET[ParamReader.get(shopId, key)]
    GET --> CACHE[(Redis 缓存)]
    GET --> DB
```

## 4. 表结构 `sys_param`
| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint PK | 主键 |
| shop_id | bigint | 租户(0=全局默认) |
| group_key | varchar | 分组 |
| param_key | varchar | 参数键(唯一) |
| param_value | varchar | 参数值 |
| remark | varchar | 说明 |
| update_time | datetime | 更新时间 |

---

## 5. 接口设计

### 5.1 POST /api/v1/sys-param/list
```json
// 请求 { "group":"cashier" }
// 响应 { code:0, data:[{param_key,param_value,remark}] }
```

### 5.2 POST /api/v1/sys-param/save
```json
{ "items":[ {"param_key":"default_discount","param_value":"0.9"} ] }
```
- 保存后失效 Redis 缓存 `param:{shopId}:{key}`。

### 5.3 读取工具（供各服务）
```java
String v = ParamReader.get(shopId, "default_discount", "1.0");
```
