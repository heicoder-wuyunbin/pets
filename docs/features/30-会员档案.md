# 功能开发文档 · 30·会员档案

> 项目：宠老板复刻 · 里程碑：M5（F-050，P0）
> 作用：管理会员基础档案（含常用宠物、会员等级、累计消费），支撑收银选会员与营销触达。

---

## 1. 功能概述

实现**会员档案管理**：会员建档 CRUD、关联宠物档案、会员等级与积分余额展示、累计充值消费统计、标签与备注。

- 核心产出：会员建档、宠物档案、会员列表与详情、积分/余额展示。
- 前置：M0、Redis 号段、M1 鉴权、与 M3 收银联动记账。

## 4. 表结构

### 4.1 会员 `member`
| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint PK | Redis 号段 |
| shop_id | bigint | 租户 |
| mobile | varchar | 手机 |
| name | varchar | 姓名 |
| gender / birthday | ... | 资料 |
| member_level | int | 等级 |
| remark | varchar | 备注 |
| create_time | datetime | |

### 4.2 宠物 `member_pet`
| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint PK | 主键 |
| member_id | bigint | 会员 |
| pet_name / type / breed | varchar | 宠物信息 |
| weight | decimal | 体重 |

### 4.3 账户 `member_account`
| 字段 | 类型 | 说明 |
|------|------|------|
| member_id | bigint PK | 会员 |
| balance | decimal | 充值余额 |
| points | int | 积分 |
| total_consume / total_recharge | decimal | 累计 |

## 5. 接口设计
- `POST /api/v1/member/create` / `edit` / `page` / `detail`。
- `POST /api/v1/member/pet/save`：宠物档案。
- 收银下单联动：扣余额/加积分（F-030/053）。

---

## 6. 前端设计
- `pages/member/List.tsx`：会员表格 + 过滤。
- `pages/member/Detail.tsx`：详情抽屉（资料/宠物/卡/积分）。
