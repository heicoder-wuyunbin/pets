# 功能开发文档 · 24·商品管理

> 项目：宠老板复刻 · 里程碑：M4（F-040，P0）
> 作用：门店可售商品库，含分类、SKU、零售价、状态，供收银与库存引用（goods-service）。

---

## 1. 功能概述

实现**商品管理**：商品分类、商品/SKU 维护、上下架、零售价/成本价、多规格(SKU)，是收银与库存的基础数据源。

- 核心产出：分类管理、商品 CRUD、SKU、上下架接口、商品管理页。
- 前置：M0 脚手架、Redis 号段、M1 鉴权。

---

## 4. 表结构

### 4.1 分类 `goods_category`
| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint PK | 主键 |
| shop_id | bigint | 租户 |
| parentid | bigint | 父分类(0=根) |
| name | varchar | 分类名 |
| sort | int | 排序 |

### 4.2 商品 `goods`
| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint PK | Redis 号段 |
| shop_id | bigint | 租户 |
| category_id | bigint | 分类 |
| name | varchar | 商品名 |
| barcode | varchar | 条码 |
| unit | varchar | 单位 |
| retail_price | decimal | 零售价 |
| cost_price | decimal | 成本价 |
| status | tinyint | 1 上架 0 下架 |
| pic | varchar | 主图 |

### 4.3 SKU `goods_sku`
| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint PK | 主键 |
| goods_id | bigint | 商品 |
| spec_name | varchar | 规格描述 |
| price | decimal | 规格价 |
| stock | int | 库存(可冗余/以 stock 为准) |

## 5. 接口设计
- `POST /api/v1/goods/category/page` / `save`：分类。
- `POST /api/v1/goods/page`：商品分页（分类/关键字/状态）。
- `POST /api/v1/goods/save`：新增/编辑（含 SKU 列表）。
- `POST /api/v1/goods/status`：上/下架。

---

## 6. 前端设计
- `pages/goods/Goods.tsx`：左分类树 + 右商品表格 + 商品编辑抽屉（含 SKU）。
- `pages/goods/Category.tsx`：分类管理。
