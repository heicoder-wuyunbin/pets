# 功能开发文档 · 28·入库管理

> 项目：宠老板复刻 · 里程碑：M4（F-044，P1）
> 作用：采购/进货入库单，入库增加库存并记账，形成供应商往来与进货成本。

---

## 1. 功能概述

实现**入库单**：录入入库商品/数量/成本/供应商，保存后增加 `stock` 余量并写入入库流水，可查询入库历史。

- 核心产出：入库单创建、库存入账、入库列表。
- 前置：M0、F-040 商品、F-043 库存。

---

## 2. 数据流

```mermaid
flowchart TD
    IN[入库单创建] --> ITEMS[选商品+数量+成本]
    ITEMS --> SAVE[保存入库单]
    SAVE --> STOCK[stock 数量增加]
    SAVE --> FLOW[(入库流水 stock_in)]
    LIST[入库列表] --> REQ[POST /stock-in/page]
    REQ --> FLOW
```

## 4. 表结构

### 4.1 入库单 `stock_in`
| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint PK | 单号 |
| shop_id | bigint | 租户 |
| supplier_id | bigint | 供应商(可空) |
| total | decimal | 总成本 |
| clerk_id | bigint | 经办 |
| create_time | datetime | |
| status | tinyint | 已入库 |

### 4.2 入库明细 `stock_in_item`
| 字段 | 类型 | 说明 |
|------|------|------|
| id | bigint PK | 主键 |
| in_id | bigint | 入库单 |
| goods_id / sku_id | bigint | 商品 |
| qty | int | 数量 |
| cost | decimal | 成本 |

---

## 5. 接口设计
- `POST /api/v1/stock-in/create`：创建+入账（事务：写单 + 加 stock + 记流水）。
- `POST /api/v1/stock-in/page`：入库历史。

---

## 6. 前端设计
- `pages/stock/Inbound.tsx`：入库单表单（商品明细动态行）+ 历史列表。
